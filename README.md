# Práctica de Git y GitHub: Mi primer repositorio PHP

Este repositorio contiene una práctica básica de control de versiones utilizando **Git** y **GitHub**. El objetivo es demostrar el flujo de trabajo fundamental: creación de un repositorio local, configuración de Git, realización de commits y sincronización con un repositorio remoto.

## 🛠️ Tecnologías y Herramientas
*   **Sistema de control de versiones:** Git (v2.54.0)
*   **Plataforma de alojamiento:** GitHub
*   **Lenguaje:** PHP
*   **Entorno:** Windows (Git Bash)

## 🎯 Conceptos Aplicados
Durante la práctica se han realizado los siguientes pasos:

1.  **Instalación y configuración de Git:**
    *   Instalación de Git en Windows.
    *   Configuración del nombre de usuario y correo electrónico globales (`git config --global`).
    *   Verificación de la versión instalada (`git --version`).
2.  **Creación del repositorio local:**
    *   Inicialización del repositorio con `git init` en la carpeta del proyecto.
    *   Creación del archivo `index.php`.
    *   Añadir el archivo al área de preparación (`git add`) y confirmación de cambios (`git commit`).
3.  **Conexión con GitHub y sincronización:**
    *   Creación de un repositorio remoto en GitHub.
    *   Vinculación del repositorio local con el remoto (`git remote add origin`).
    *   Subida de los cambios a la nube (`git push`).
    *   Edición del archivo directamente desde GitHub y posterior actualización en local (`git pull`).

## 📄 Contenido del repositorio
*   **`index.php`**: Archivo PHP que contiene una función básica de saludo (`saludar`) y su llamada. Sirve como ejemplo de archivo de código para versionar.
